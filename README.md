# Талисманы для Streets of Rogue

Фанатский мод, версия 1.7.40. К игре Matt Dabrowski и к Miraculous он не относится.

Девятнадцать предметов для своего персонажа. Каждый надевает костюм и даёт суперсилу на правую кнопку мыши. Повторное использование того же предмета сразу снимает костюм. Новый костюм снимает прежний. После снятия предмет молчит 20 секунд, остаток написан красным числом на иконке.

Предметы сами никому не выдаются. Их выбирают в редакторе своего персонажа. У бомжа их нет. Хватит одной штуки каждого.

Пока своя скорость ниже 4, костюм поднимает её до 4. Силу ближнего боя меняют только кот и Ледибаг: если своя была ниже 3, становится 3. Остальные силу не трогают. Оружие костюма есть только пока он надет. Промах суперсилы заряд не тратит. Таймер костюма начинается после успешной суперсилы.

## Установка

Пакет для Windows лежит в папке `Talismans-Pack`. Внутри уже есть загрузчик BepInEx 5.4.23.2, библиотека RogueLibs 4.0.0-rc.3 и сам мод. RogueLibs этой версии рассчитан на игру v99d.

1. Полностью закрой Streets of Rogue.
2. Открой папку игры, где лежит `StreetsOfRogue.exe`. У GOG это обычно `C:\GOG Games\Streets of Rogue`. В Steam: библиотека, правый клик по игре, Управление, Просмотреть локальные файлы.
3. Скопируй содержимое `Talismans-Pack` в папку игры. Рядом с exe должны оказаться `winhttp.dll`, `doorstop_config.ini` и папка `BepInEx`. Если Windows спросит про замену, соглашайся только когда ставишь этот пакет заново на чистую игру: уже стоящий другой BepInEx эта копия заменит.
4. Запусти игру до главного меню. Появится `BepInEx\config\catnoir.ring.cfg`.

Если BepInEx и RogueLibs 4.0.0-rc.3 уже стоят, полный пакет лучше не распаковывать. Положи только `Talismans-Pack\BepInEx\plugins\CatNoirRing.dll` в `BepInEx\plugins` своей игры. Без RogueLibs мод не загрузится. Вместе с ECTD не ставь: он конфликтует с RogueLibs.

Дальше открой редактор своего персонажа и выдай нужные предметы. Готовый персонаж вроде бомжа их сам не получает.

`winhttp.dll` должен лежать рядом с exe, не внутри `BepInEx`. Антивирус иногда его удаляет: верни файл из `Talismans-Pack` и добавь папку игры в исключения. В `BepInEx\LogOutput.log` при удачном запуске есть строки `RogueLibs v4.0.0-rc.3` и `Cat Noir Ring 1.7.40`.

Убрать только мод: удали `BepInEx\plugins\CatNoirRing.dll`. Убрать загрузчик, если его поставил этот пакет и другие моды не нужны: удали `winhttp.dll`, `doorstop_config.ini` и папку `BepInEx`. Сохранения не трогаются.

Полный текст для игрока, включая настройки, лежит в `Talismans-Pack/УСТАНОВКА.txt`.

## Костюмы

| Предмет | Суперсила на правой кнопке |
| --- | --- |
| Кольцо Cat Noir | Катаклизм один раз ломает стену впереди или тяжело ранит существо. Шест. Затем 15 секунд |
| Серьги Ледибаг | Лаки Чарм один раз достаёт случайную квестовую награду. Йо-йо возвращается в руку. Затем 15 секунд |
| Талисман мыши | Умножение делает тебя маленьким и зовёт трёх мелких союзников. Скакалка. Через минуту костюм спадает |
| Талисман пчелы | Веном парализует существо впереди на 15 секунд, без урона. Цель и ближайшие союзники злятся. Тромпо возвращается. Затем 15 секунд |
| Талисман змеи | Второй шанс запоминает мир на 30 секунд. Следующее нажатие до нуля возвращает к снимку и снова ставит 30 секунд. Смерть и нокаут при живом снимке откатывают сами |
| Талисман лошади | Путешествие открывает лифт районов: тот же герой продолжает с первого этажа выбранного района. Телепорт с карты квестов, который обходит запрет, запускает 15 секунд |
| Камень Тигрицы | Удар: 30 урона и швыряет существо сквозь стены. Затем 15 секунд |
| Камень Собаки | Мяч метит и не ранит. Апорт ворует одну вещь у отмеченного. Пустой карман или полная сумка заряд не тратят. Затем 15 секунд |
| Камень Козы | Генезис выдаёт один предмет из списка, даже ещё закрытый. Закрытие без выбора заряд не тратит. Затем 15 секунд |
| Камень Петуха | Сублимация даёт одну полезную черту на минуту. Черта живёт только в этом костюме |
| Камень Дракона | По кругу: ветер, вода и тазер. Минута идёт с первого оружия, замена ствола её не сбрасывает |
| Камень Быка | Сопротивление снимает вредные статусы, как антидот, и его можно жать снова. Первое применение запускает 15 секунд |
| Камень Обезьяны | Банан метит и не ранит. Смятение на 15 секунд переворачивает отмеченному шаг. Без метки заряд не тратится. Затем 15 секунд |
| Камень Павлина | Амок один раз призывает союзника из списка классов на минуту. Повтор или снятие костюма отзывает его |
| Камень Лисы | Мираж один раз ставит голограмму йети. Затем 15 секунд |
| Камень Свиньи | Подарок: человек впереди забывает обиды и становится дружественным ко всем. Дружелюбие остаётся. Затем 15 секунд |
| Камень Черепахи | Панцирь ставит поле, которое отражает атаки и не подпускает ближе. Ещё раз убирает поле. Первое нажатие запускает 15 секунд |
| Камень Бабочки | Акума один раз превращает человека впереди в случайную нечеловеческую расу и вгоняет в бешенство. Костюм держится минуту. Повтор или снятие возвращает облик, если существо живо |
| Камень Кролика | Остановка времени на 10 секунд: существа, камеры, ловушки и таймеры замирают. С этого нажатия костюм держится 15 секунд |

Пока маска надета, старые обиды спадают, если человек не видел превращение. Кто смотрит, обиду не забывает. Обиды каждой маски помнятся отдельно.

## Сборка

Папка `CatNoirRing` должна лежать прямо в папке игры, рядом с `StreetsOfRogue.exe`. Из папки игры:

```text
dotnet build CatNoirRing\CatNoirRing.csproj -c Release --nologo
```

Нужен .NET SDK. Сборка копирует DLL в `BepInEx\plugins`. Игру после этого полностью перезапускают. Для пакета другому игроку ту же DLL копируют в `Talismans-Pack\BepInEx\plugins`.
