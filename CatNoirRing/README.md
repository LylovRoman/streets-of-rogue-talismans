# Талисманы

Мод для Streets of Rogue, версия 1.7.40. Девятнадцать предметов. Каждый надевает костюм и даёт суперсилу на правую кнопку мыши. Повторное использование того же предмета сразу снимает костюм. Новый костюм снимает прежний. После снятия предмет молчит 20 секунд, остаток написан красным числом на иконке.

Предметы сами никому не выдаются. Их выбирают в редакторе своего персонажа. У бомжа их нет.

Пока своя скорость ниже 4, костюм поднимает её до 4. Силу ближнего боя меняют только кот и Ледибаг: если своя была ниже 3, становится 3. Остальные силу не трогают. Оружие костюма есть только пока он надет. Промах суперсилы заряд не тратит. Таймер костюма начинается после успешной суперсилы.

Пока маска надета, старые обиды спадают, если человек не видел превращение. Кто смотрит, обиду не забывает. Обиды каждой маски помнятся отдельно. Свои прежние обиды возвращаются вместе с человеческим обликом.

## Как поставить

Пакет для другого игрока — папка `Talismans-Pack` рядом с этим проектом. Текст для него лежит в `Talismans-Pack/УСТАНОВКА.txt`.

Чистая игра, Windows: скопировать содержимое `Talismans-Pack` в папку, где лежит `StreetsOfRogue.exe`. Рядом с exe оказываются `winhttp.dll`, `doorstop_config.ini` и папка `BepInEx`. В пакете уже есть BepInEx 5.4.23.2, RogueLibs 4.0.0-rc.3 и `CatNoirRing.dll`. Один раз запустить игру до главного меню.

Уже стоят BepInEx и RogueLibs 4.0.0-rc.3: положить только `BepInEx/plugins/CatNoirRing.dll`. Полный пакет поверх чужого загрузчика лучше не копировать, он заменит BepInEx и RogueLibs. ECTD с этим пакетом не ставится.

Убрать мод: удалить `BepInEx/plugins/CatNoirRing.dll`. Убрать загрузчик, если его поставил этот пакет: удалить `winhttp.dll`, `doorstop_config.ini` и папку `BepInEx`. Сохранения не трогаются.

`winhttp.dll` должен лежать рядом с exe. Антивирус иногда его удаляет.

## Сборка

Проект лежит внутри папки игры, на уровень выше — `StreetsOfRogue.exe`. Из этой папки:

```text
dotnet build CatNoirRing\CatNoirRing.csproj -c Release --nologo
```

Нужен .NET SDK. Сборка копирует `CatNoirRing.dll` в `BepInEx\plugins`. Пока игра запущена, она держит старую DLL: её надо полностью закрыть и открыть снова.

Если правка идёт в пакет для другого игрока, ту же DLL нужно скопировать в `Talismans-Pack\BepInEx\plugins`.

## Настройки

Появляются после первого запуска: `BepInEx/config/catnoir.ring.cfg`.

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| FormDuration | 15 | Секунды кота, Ледибаг, пчелы, лошади, тигрицы, собаки, козы, быка, обезьяны, лисы, свиньи, черепахи и хвост кролика после суперсилы |
| FormCooldown | 20 | Пауза предмета после снятия костюма |
| StaffDamage | 8 | Удар шеста и скакалки |
| CataclysmDamage | 30 | Урон катаклизма по существу |
| CloutDamage | 30 | Урон удара тигрицы |
| YoYoDamage | 10 | Урон йо-йо и тромпо |
| MultiplyDuration | 60 | Секунды умножения и костюма мыши |
| ParalysisDuration | 15 | Секунды паралича Венома |
| SecondChanceDuration | 30 | Секунды Второго шанса |
| SublimationDuration | 60 | Секунды костюма петуха после выбора черты |
| ConfusionDuration | 15 | Секунды смятения обезьяны |
| DragonDuration | 60 | Секунды костюма дракона с первого оружия |
| PeacockDuration | 60 | Секунды костюма павлина после призыва |
| ButterflyDuration | 60 | Секунды костюма бабочки после превращения |
| TimeStopDuration | 10 | Секунды остановки времени |

После правки файла игру перезапускают.
